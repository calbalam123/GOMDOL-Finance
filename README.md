# GOMDOL Finance

GOMDOL Wallet, Exchange & Economy platform.

## Project status

- Token: GOMDOL (ERC-20)
- Network: Ethereum Sepolia (testnet)
- Contract: `0xCaC4e5AF15e697e65d9CFf302B64aF1307f9E7Df`
- Initial supply: 100,000,000 GOMDOL

This project is a testnet prototype. Sepolia assets have no real-world monetary value.

## Planned modules

- `frontend/` — React + Vite dashboard
- `backend/` — Node.js + Express API
- `database/` — SQLite schema and migrations
- `contracts/` — Solidity contracts and tests
- `.github/workflows/` — CI checks

## Security

Never commit private keys, seed phrases, RPC secrets, or `.env` files. Use MetaMask for wallet signing; the backend must never custody user private keys.
